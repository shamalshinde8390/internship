# Week 2 Documentation: Styled Portfolio Website

## Project overview
This project improves the Week 1 portfolio by adding an external CSS stylesheet, a consistent color palette, typography, responsive layouts, and interactive hover states.

## Technologies
- HTML5
- CSS3
- Google Fonts (Inter)

## Main features
- About, Skills, and Contact sections with internal navigation
- CSS custom properties for colors and reusable values
- Flexbox navigation and action buttons
- CSS Grid for the hero, skills, and contact layouts
- Hover transitions for links, buttons, and skill cards
- Media queries for tablet and mobile layouts
- Form labels, required fields, email validation, and keyboard focus indicators

## Files and folders
- `index.html`: page content and semantic structure
- `style.css`: all visual styling and responsive rules
- `images/`: add `profile.jpg`
- `screenshots/`: add desktop and mobile screenshots
- `README.md`: setup and test instructions

## Run the project
1. Open the project folder in VS Code.
2. Add a profile photo at `images/profile.jpg`.
3. Update placeholder name, text, and email.
4. Open `index.html` in a browser or use VS Code Live Server.

## Testing
Test navigation, hover states, form validation, image alt text, and layouts at desktop, tablet, and mobile widths. Capture screenshots and save them in the `screenshots/` folder.

## Limitation
The contact form uses `mailto:`. It does not provide server-side submission handling. A backend or form service is needed for reliable production use.
