# My Portfolio Website

A beginner-friendly personal portfolio made with HTML5.

## Sections
- About
- Skills
- Contact

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your web browser.

## Customize
- Replace `Your Name` and the sample text with your own details.
- Add your profile photo as `images/profile.jpg`.
- Replace `you@example.com` in the contact form with your email address.

## Note
The contact form uses `mailto:` and opens the visitor's default email app. For reliable online form handling, connect a backend or form service.
